# 斗地主

入口与现有棋类相同：选择本地对战或创建/加入房间，再进入牌桌。本地由一位玩家与两位电脑对战；在线房间提供三个座位，三人入座后由房主开始，其他加入者可观战。无需微信或 QQ 登录。

## 规则范围

采用经典三人、一副 54 张牌的叫分玩法，每人 17 张，留 3 张底牌。按顺序选择不叫或高于前次的 1/2/3 分；叫 3 分直接确定地主，否则三人叫完取最高者。全不叫自动重新发牌。地主取得底牌并先出牌。

支持单张、对子、三张、三带一、三带二（必须为对子）、顺子、连对、飞机及单翼/对翼、四带两张/两对、炸弹、王炸。顺子和连续牌型不得包含 2 或王。飞机主干必须连续、每个点数恰为三张；单翼允许对子拆作两张，但不允许三张或四张相同点数作为翼，对翼必须是不同点数的对子。四带两张允许带一对。

普通牌必须牌型、张数相同且主干更大；炸弹压普通牌，王炸最大。连续两人不出后，由上一手出牌者重新领出。地主先出完则地主获胜，任一农民先出完则农民共同获胜。叫分作为基础倍数，炸弹、王炸及春天翻倍。春天是地主胜且农民未出牌，或农民胜且地主只出过一手。只展示本局倍数，不设金币、充值或累计积分。

点击手牌选择，点击“出牌”提交。“提示”可反复点击切换候选。电脑以合法牌型和简单队友配合为主，不读取其他玩家未公开的牌来决策。动画包含选牌抬起和出牌入桌，遵循系统减少动态效果偏好。

## 联机与隐私

迁移文件：`supabase/migrations/20261002000000_doudizhu.sql`。

新增 `doudizhu_rooms`（公开状态）、`doudizhu_room_members`（加入记录）、`doudizhu_deals`（私有手牌和底牌）。客户端只能读取已加入房间；私有牌库禁止客户端直接读取、修改，也不加入 Realtime。快照函数按登录身份只返回本人的手牌，观战者获得空手牌。未确定地主前底牌不公开。

发牌、叫分、牌型、持牌归属、轮次、胜负、重开均在服务端处理。提交携带状态版本，重复或过期操作被拒绝。公开房间更新触发客户端重新获取自己的快照；保留可见页面 10 秒轮询、网络恢复和刷新重进房间。

刷新或重新加入请使用原浏览器，以保留游客身份和座位。离开牌桌不会把已开始对局的座位让给别人；断线玩家恢复后继续。当前不提供联机机器人补位或自动代打。

## 验证

`npm test` 覆盖牌型、非法输入、轮次、叫分重发、炸弹/春天及电脑完整随机对局。`npm run test:render` 覆盖入口和观战牌面。数据库检查可执行：

```bash
node scripts/check-doudizhu-db.mjs /absolute/path/to/pglite/dist/index.js
```

该检查在临时 PostgreSQL 中验证三人房间、手牌隐私、直接读写拒绝、完整出牌/重开，并交叉核对前端和服务端牌型识别。

牌型参照：[完美世界斗地主出牌规则](https://zhuxian.wanmei.com/infostation/yxfz/20091217/38168.shtml)。不同平台的飞机翅膀存在差异，本项目采用上文明确的范围。
