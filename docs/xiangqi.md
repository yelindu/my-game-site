# 中国象棋本地双人

从大厅点击“中国象棋”，两人在同一台设备轮流操作。黑方在上，红方在下，红方先行。点击当前方棋子后，绿色标记表示合法目标；点击标记完成移动或吃子，再点已选棋子可取消选择。

## 已实现的规则

- 车直走，不能越子；马走日字，马腿被占用时不能走。
- 象走田字，检查象眼，不能过河；士与将帅限制在己方九宫。
- 炮普通移动不越子，吃子必须隔恰好一个棋子。
- 兵卒只向前走，过河后可横走，不能后退。
- 不能走到己方棋子的位置，不能送将或让将帅照面。
- 被将军后，只允许解除将军的走法。
- 对手没有合法走法时判负：被将军为将死，否则为困毙。

基本走法与胜负规则参考 [世界象棋联合会规则](https://www.wxf-xiangqi.org/images/wxf-rules/2018_World_XiangQi_Rules_English2018.pdf)。本版提供休闲玩法，不自动裁判比赛中的长将、长捉、循环局面、自然限着或超时；双方可协商后点击“双方同意和棋”，再确认结束。

## 对局控制

“悔棋一步”恢复上一手的棋盘、被吃棋子与轮次，包括撤回将死或困毙结算。“重新开始”清空本局，有走棋记录时需页面内确认。“双方同意和棋”同样需要确认，取消不会改变对局。

状态仅保存在当前页面，刷新或返回大厅后重新开局。棋盘适配手机；本地双人不调用云端房间接口。

## 验证

`npm test` 检查标准开局、轮次、非法输入、吃子与悔棋、车炮阻挡、马腿/象眼、红黑过河和九宫限制、送将/照面/应将、将死/困毙、和棋后停止走子。

浏览器还需检查选择与目标提示、实际吃子、轮次变化、悔棋、确认和取消、重开、手机布局及大厅返回。`npm run build` 检查生产构建；发布由已有 GitHub Pages 工作流执行。
